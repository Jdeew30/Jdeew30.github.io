Tes Meilleurs Clips

Politique de confidentialité

Dernière mise à jour : 28 octobre 2026

Cette politique concerne l'application Clipper, l'outil interne de la chaîne « Tes Meilleurs Clips ». Clipper publie des vidéos sur la chaîne YouTube de son propriétaire.

Utilisation des services d'API YouTube

Clipper utilise les services d'API YouTube (YouTube API Services). En utilisant Clipper, vous acceptez les Conditions d'utilisation de YouTube. Les données traitées par YouTube et Google le sont selon les Règles de confidentialité de Google.

Données consultées et utilisées

  • Seul le propriétaire de la chaîne se connecte à Clipper, avec son compte Google.
  • Clipper demande une seule autorisation : youtube.upload, qui permet d'envoyer des vidéos sur cette chaîne, avec leur titre, leur description et leur miniature.
  • Clipper ne consulte aucune autre donnée du compte Google (ni e-mail, ni contacts, ni historique), et aucune donnée des spectateurs ou d'autres utilisateurs.

Données conservées

  • Le jeton d'accès accordé par le propriétaire est conservé chiffré, dans les secrets d'un dépôt GitHub privé. Il sert uniquement à publier les vidéos.
  • Les vidéos sont montées sur les serveurs de GitHub Actions. Une copie de travail est conservée 7 jours dans ce dépôt privé, puis supprimée automatiquement.
  • Clipper ne place aucun cookie et ne stocke rien sur l'appareil des visiteurs. Ce site n'utilise ni cookie ni outil de mesure d'audience.

Partage

Aucune donnée d'utilisateur Google n'est vendue, partagée ni transmise à des tiers, ni utilisée pour de la publicité. Les clips d'origine proviennent de Twitch, où ils sont publics. Pour choisir les clips et rédiger les textes, leur contenu (transcription et quelques images) est envoyé à l'API Claude d'Anthropic. Ce contenu ne contient aucune donnée d'utilisateur Google.

Suppression des données

  • Les copies de travail des vidéos sont supprimées automatiquement au bout de 7 jours.
  • Après révocation de l'accès (voir ci-dessous), le propriétaire supprime le jeton des secrets du dépôt GitHub. Aucune autre donnée Google n'est conservée.
  • Sur simple demande à l'adresse de contact, toute donnée conservée est supprimée sous 7 jours. Les vidéos publiées peuvent être supprimées à tout moment depuis YouTube Studio.

Révoquer l'accès

Le propriétaire du compte peut retirer l'accès de Clipper à tout moment depuis la page des autorisations de son compte Google. Le jeton conservé devient alors inutilisable.

Contact

Pour toute question, ou pour demander le retrait d'une vidéo : jdeclip2024@gmail.com.

Privacy policy (English)

This policy covers Clipper, the internal tool of the Tes Meilleurs Clips channel, which uploads videos to its owner's YouTube channel.

  • YouTube API Services. Clipper uses YouTube API Services. By using Clipper, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
  • Data accessed. Only the channel owner signs in. Clipper requests a single scope, youtube.upload, to upload videos with their title, description and thumbnail. It accesses no other Google account data and no data about viewers or other users.
  • Data stored. The OAuth token is stored encrypted as a secret in a private GitHub repository and is only used to upload videos. Rendered videos are kept for 7 days in that private repository, then deleted. No cookies are used, by Clipper or by this website.
  • Sharing. No Google user data is sold, shared with or transferred to third parties, or used for advertising. Clip content (transcripts and a few frames of public Twitch clips, no Google user data) is sent to Anthropic's Claude API to select clips and write titles.
  • Data deletion. Working copies of videos are deleted automatically after 7 days. After access is revoked, the owner deletes the token from the GitHub repository secrets; no other Google data is stored. On request to the contact address, any stored data is deleted within 7 days. Published videos can be deleted at any time from YouTube Studio.
  • Revoking access. The account owner can revoke Clipper's access at any time from the Google security settings page.
  • Contact. jdeclip2024@gmail.com
